r10164 beta 20261019

Beta 通道 GHA 快照（无 GitHub Release）。r10164 (16928f066)，相对 r10036 beta-20260924 的变更。

更新提示：

  • 请从 Actions 下载 aegisub-win-x64-portable.zip
  • 可以只覆盖 exe，主要依赖库无更新
  • 如果需要完整 Lua 工作区调试功能需要复制 runtimes/LuaLS 目录
  • 简体中文翻译有更新，如需要可以从 Actions 下载

编辑与界面

  • 字幕栏

    • 右键菜单新增用 \N 连接（edit/line/join/with_line_breaks）：与 edit/line/join/concatenate（空格连接）类似，只是连接使用 \N
    • 右键菜单新增按空白字符分割行（edit/line/split/by_whitespace）：按空格、制表符和其他 Unicode 空白（含全角空格）分割所选行，时间保持不变并自动选择分割后的所有行
    • 折叠列可以通过列表头右键菜单控制是否启用，开启时无分组自动隐藏，默认启用

  • 编辑框（wxSTC）

    • 颜色标签点击弹出选择框改为独立偏好 Subtitle/Highlight/Color Swatches Click to Edit（默认关闭）
    • 修复光标停在完整标签块中间时的跨行 override 编辑错位
    • 修复文本重载后选区/光标丢失，如切换字体预览、取消字体对话框等场景
    • 命令按钮 / 工具栏：修复自定义按钮丢失的问题

  • 字体

    • 字体对话框和 \fn 只有明确修改字体名字时才更改
    • 修复首次 Apply/OK 把未改动的字体当成家族变更，导致手动设置的 Bold / Italic 被隐式变体覆盖
    • 应用「字体可移植性」修复时先逐行暂存并核对原始 family 名，避免继承或后续状态的字体被连带改写
    • File 菜单下新增字体使用清单（tool/font_usage_inventory）：扫描字幕文件文件或目录，展示聚合字体使用次数（同文件同时间会去重），区分缺失字体、缺字形、可操作的变体警告和低频使用；悬浮查看细节、可复制纯名称或完整明细，随目录和系统字体变化自动刷新
      • CLI对应使用：Aegisub.exe fontcollector inventory <文件或目录> [--recursive] [--low-frequency-threshold N] [--json]

  • 搜索替换

    • 替换结果对话框按字幕行聚合，一次显示完整的前后文本
    • 一些搜索和替换、卡拉OK的 bug 修复和性能优化

  • Shift Times / 计时处理器 / Align to Video：优化数值转换和避免静默报错

可视化排版

  • 新增 Shear（video/tool/shear），位于 Vector Clip 下方，新增热键上下文 Visual Shear 和偏好 Tool/Visual/Nudge/Shear Step(Large)
    • 拖拽单轴调整 fax / fay，方向键微移，Ctrl+Home / Ctrl+End 把对应轴归零（video/tool/shear/reset/x、video/tool/shear/reset/y）
    • 只接受静态 shear，动画会被拒绝
  • 测量工具（Perspective）：新增可选 最佳拟合（不化简）（Tool/Visual/Perspective/Best Fit，Preferences 和工具栏同项开关），输出完整标签集，只受 Fit Text 和小数位数影响
  • 可视化工具新增 几何链接 开关（video/tool/geometry_linking）：开启时变化可以同步更新 \org、\clip
  • 修复矩形 \iclip 误判：多行矩形裁剪编辑改为逐行解析 override 块，字幕正文里字面的 \iclip 文本不再把普通裁剪改成反向裁剪

视频 / 渲染

  • Windows OpenGL 画布改用 DXGI 呈现：规避某些 NVIDIA / Windows 组合下 DWM 合成阶段的长时间卡顿；不支持的上下文或初始化失败时仍回退原生 SwapBuffers
    • 需要对比排查时可在启动前通过 AEGISUB_ENABLE_DXGI_PRESENTATION=0 关闭（进程级，不改显卡驱动配置）
  • 关键帧生成：优化文件缓存和读取
  • 字幕渲染：回填上游精度保护，修复整数毫秒 → 秒 → 毫秒往返后起始帧提前 1 ms（libass / CSRI）

音频

  • 新增 Shift+鼠标滚轮 纵向缩放音频显示
  • 修复XAudio2 和 Skia 音频显示偶发视频跳回开头的问题
  • 切换音频后端时不再弹出多音轨选择

自动化

新增 Lua 工作区（Lua Workspace），独立的 Lua 代码编辑 / 运行 / 调试面板。完整的补全、签名提示、悬浮、诊断等依赖 LuaLS。

  • 入口
    • 编辑框 / 字幕栏：在 Lua 工作区中打开代码行（automation/lua/open-current-line），只对 coding line 生效，可以使用 Shift+Enter 快速打开
    • Automation Manager：新增 Edit in Lua Workspace 按钮

其他

  • 优化长路径、覆盖保存、自动保存副本处理、目录监控
  • 优化字幕导入编码识别，先识别严格合法的非 ASCII UTF-8，再走统计检测，短 SRT 里带增补平面字符不再被当成二进制
  • EBU STL：时间码偏移的帧分量不再被忽略，drop-frame 和含尾端语义不变
  • 增补简体中文翻译
  • 新增按文本长度排序（grid/sort/text_length）和按去除标签的文本长度排序（grid/sort/text_stripped_length）

构建

  • 新增跨平台 Clang / clang-cl 构建：Windows 和 Linux 测试过编译，macOS 未测试
  • 自动化构建新增翻译文件的构建
