r10164 beta 20261019

Beta channel GHA snapshot (no GitHub Release). r10164 (16928f066); changes since r10036 beta-20260924.

Update notes:

  • Download aegisub-win-x64-portable.zip from Actions
  • Replacing only the exe is enough; no main dependency library was updated
  • Copy the runtimes/LuaLS directory if you want the full Lua Workspace debugging features
  • The Simplified Chinese translation was updated; download it from Actions if needed

Editing and UI

  • Subtitle grid

    • New Join with \N in the context menu (edit/line/join/with_line_breaks): like edit/line/join/concatenate (space-joined), but joins with \N
    • New Split lines by whitespace in the context menu (edit/line/split/by_whitespace): splits the selected lines at spaces, tabs and other Unicode whitespace (including full-width spaces), keeps their times, and selects all resulting lines
    • The folding column can be enabled or disabled from the column header context menu; when enabled it still hides itself for files without groups. Enabled by default

  • Edit box (wxSTC)

    • Clicking a color tag to open the picker is now a separate preference, Subtitle/Highlight/Color Swatches Click to Edit (off by default)
    • Fix cross-line override editing when the caret sits inside a complete tag block
    • Fix lost selection and caret after text reloads, such as switching font previews or cancelling a font dialog
    • Command buttons / toolbar: fix custom buttons being lost

  • Fonts

    • Font dialogs and \fn only change the font name when it is explicitly edited
    • Fix the first Apply/OK treating an unchanged font as a family change, which discarded manual Bold / Italic settings in favour of the implicit variant
    • Applying font portability fixes now stages each row first and re-checks the original family name, so inherited or later font states are not rewritten along the way
    • New Font Usage List in the File menu (tool/font_usage_inventory): scans subtitle files or directories and shows aggregated font usage counts (deduplicated per file and time range), distinguishing missing fonts, missing glyphs, actionable variant warnings and low-frequency usage; hover for details, copy either bare names or the full details, and it refreshes when directories or system fonts change
      • The matching CLI is Aegisub.exe fontcollector inventory <file-or-dir> [--recursive] [--low-frequency-threshold N] [--json]

  • Search and replace

    • The replacement results dialog groups by subtitle line and shows the complete before and after text at once
    • Various bug fixes and performance improvements in search, replace and karaoke

  • Shift Times / the timing processor / Align to Video: improved numeric conversion and no more silent failures

Visual typesetting

  • New Shear tool (video/tool/shear), placed below Vector Clip, with a new Visual Shear hotkey context and the Tool/Visual/Nudge/Shear Step(Large) preferences
    • Drag a single axis to adjust fax / fay, nudge with the arrow keys, and reset an axis to zero with Ctrl+Home / Ctrl+End (video/tool/shear/reset/x, video/tool/shear/reset/y)
    • Only static shear is accepted; animated layouts are rejected
  • Measure tool (Perspective): new optional Best Fit (No Reduction) (Tool/Visual/Perspective/Best Fit, a shared toggle in Preferences and the toolbar) that emits the complete tag set and is only affected by Fit Text and Decimal Places
  • New Geometry Linking toggle for visual tools (video/tool/geometry_linking): when enabled, geometry edits also update attached \org and \clip tags
  • Fix rectangular \iclip misdetection: multi-row rectangle clip editing now parses override blocks per row, so literal \iclip text in the subtitle body no longer turns a normal clip into an inverse clip

Video / rendering

  • Windows OpenGL canvases now present through DXGI, avoiding long DWM composition stalls on some NVIDIA / Windows combinations; unsupported contexts or failed initialization still fall back to native SwapBuffers
    • For comparison, set AEGISUB_ENABLE_DXGI_PRESENTATION=0 before starting the process (process-wide; no driver profile is modified)
  • Keyframe generation: improved file caching and reads
  • Subtitle rendering: backported upstream precision guards, fixing start frames rendering 1 ms early after the integer millisecond → seconds → millisecond round trip (libass / CSRI)

Audio

  • New Shift+mouse wheel vertical zoom for the audio display
  • Fix occasional video jumping back to the start in XAudio2 and Skia audio display
  • Switching the audio backend no longer pops up a multi-track selection

Automation

New Lua Workspace, a standalone Lua code editing / running / debugging panel. Full completion, signature help, hover and diagnostics depend on LuaLS.

  • Entry points
    • Edit box / subtitle grid: Open Code Line in Lua Workspace (automation/lua/open-current-line), only for coding lines; Shift+Enter opens it quickly
    • Automation Manager: new Edit in Lua Workspace button

Other

  • Improved long path handling, replace-on-save, autosave copy handling and directory watching
  • Improved subtitle import charset detection: strictly valid non-ASCII UTF-8 is recognized before statistical detection, so short SRT files with supplementary-plane characters are no longer treated as binary
  • EBU STL: the frame component of the timecode offset is no longer ignored, with drop-frame and inclusive-end semantics unchanged
  • Added Simplified Chinese translations
  • New sorting by text length (grid/sort/text_length) and by stripped text length (grid/sort/text_stripped_length)

Build

  • New cross-platform Clang / clang-cl builds: compile-tested on Windows and Linux, not tested on macOS
  • The automated build now also builds the translation files
