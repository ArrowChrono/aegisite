**Beta 通道** GHA 快照（无 GitHub Release）。r10010，相对 [r9990 beta-20260911](/zh-cn/changelog/beta-20260911/) 的变更。本次只需要更新 Aegisub 本体和 lsmasnative 动态库。

请从 [Actions](https://github.com/AmusementClub/Aegisub/actions/runs/35236156334) 下载 `aegisub-win-x64-portable.zip`。

### 编辑与界面

- 编辑框（wxSTC）：修复可能造成编辑框空白或保留错误文本的问题
- 取色放大镜：消除指针移动时的灰色闪烁

### 可视化排版

- 运动追踪：新增仿射（Affine，包含剪切/非均匀缩放）和透视（Perspective / 单应性 Homography，含 `\org`、`\clip` 等）追踪模型及 ASS 标签回写
  - ASS 标签输出语法修正：非 move、fad 等标签直接输出数值，不再带多余的括号
  - 支持在不同 Apply 模式间复用已分析的轨迹

- 测量工具（Perspective）：改进标签生成

### 视频 / 对帧

- 视频：修复 detached video 在打开视频或自动生成关键帧后的窗口异常缩小为 0
- 对帧工具：
  - 支持跨场景切换追踪淡入淡出文本，优化笔画边缘检测和浅色背景干扰
  - 提升长 fade 的检出率

### 音频

- 提高频谱和波形渲染稳定性和缺失修复，涉及 lsmasnative 和 Avisynth provider

### 构建 / 打包 / 运行时

- 更新 lsmasnative 依赖至 202608 版本
