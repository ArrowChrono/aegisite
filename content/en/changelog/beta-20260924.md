**Beta channel** GHA snapshot (no GitHub Release). r10036 (59567775c); changes since [r10010 beta-20260917](/changelog/beta-20260917/). Only the Aegisub binary needs to be updated this time.

Download `aegisub-win-x64-portable.zip` from [Actions](https://github.com/ArrowChrono/Aegisub/actions/runs/36023445388).

### Editing and UI

- Color picker: add ASS hexadecimal alpha input, supporting ASS notation (such as `&H00&`) and raw hexadecimal values; synchronized in real time with decimal input, slider, and live preview
- Project properties: fix missing Project Properties (Project Garbage) in save snapshots and autosave backups
- Performance: optimize subtitle text commit logic to skip time-box repaints when only plain text changes, reducing unnecessary UI control refreshes

### Visual typesetting

- Visual tools: general performance improvements
- Motion tracking:
  - Compact mode optimization: prefer keeping motion in single-line events to emit more compact and cleaner ASS tags; default pixel budget increased from 0.75 to 1 px
  - Adjust option names to avoid translation ambiguity
  - Add diagnostic data export

### Audio

- OpenGL: resolve black tiles / visual gaps in audio display
- Matroska Opus sample timeline alignment:
  - Fix timeline offset for Opus tracks in MKV containers (when libmatroska is enabled)
  - Improve audio sample accuracy during uncached random seeks
- XAudio2: improve playback endpoint handling and progress reconstruction
- Audio clip export: fix silently exporting corrupted silent or truncated WAV files on error

### Build / testing / runtime

- Build: stabilize vcpkg ABI toolchain configuration to minimize rebuilds; prune old NuGet binary caches automatically
