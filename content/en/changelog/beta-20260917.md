**Beta channel** GHA snapshot (no GitHub Release). r10010; changes since [r9990 beta-20260911](/changelog/beta-20260911/). Only the Aegisub binary and the lsmasnative dynamic library need to be updated this time.

Download `aegisub-win-x64-portable.zip` from [Actions](https://github.com/AmusementClub/Aegisub/actions/runs/35236156334).

### Editing and UI

- Edit box (wxSTC): fix issues that could leave the editor blank or retain incorrect text
- Color picker magnifier: eliminate grey flicker while moving the pointer

### Visual typesetting

- Motion tracking: add Affine (shear and non-uniform scale) and Perspective (homography, including `\org`, `\clip`, etc.) tracking models with ASS tag writeback
  - ASS tag output syntax fix: scalar tags are emitted directly with values without redundant parentheses (unlike tags with parameter lists such as `\move` or `\fad`)
  - Support reusing analyzed trajectories across different Apply modes

- Measure tool (Perspective): improve tag generation

### Video / Align to video

- Video: fix detached video window unexpectedly shrinking to size 0 after opening video or auto-generating keyframes
- Align tool:
  - Support tracking fading text across scene changes; improve stroke edge detection and tolerance against pale background interference
  - Improve detection rates for long fades

### Audio

- Improve spectrum and waveform rendering stability and fix missing display gaps, covering lsmasnative and Avisynth providers

### Build / packaging / runtime

- Update lsmasnative dependency to 202608
